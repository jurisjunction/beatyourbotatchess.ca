# beatyourbotatchess.ca

The public page of Beat Your Bot at Chess (Teresa's Pawn), from Luktor Labs,
served by GitHub Pages from `main`.

- `index.html` is the page; the diagram inside it is generated:
  `python3 tools/board.py` (needs python-chess, for the pieces).
- Pieces: Colin M.L. Burnett, BSD licence (`pieces-LICENSE.txt`).
- `fonts/`: Alegreya and Alegreya Sans, under the SIL Open Font License.
- The site loads nothing from anyone else and sets no cookies. Keep it so.
- It says what the player sees, never how the bot is built.
